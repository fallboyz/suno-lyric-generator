# Suno Lyric Generator

**Suno Lyric Generator** is a professional tool designed to help you craft lyrics and style prompts optimized for music generation with **Suno AI (V5 & V6)**.

## Key Features

* **368 Tags across 12 Categories**
  A massive collection of community-verified Suno tags covering structure, vocals, instruments, genres, moods, mixing, sound effects, and more.

* **Smart Tag System**
  Click any tag to instantly insert it into the lyric editor or style prompt. Structure tags (`[Intro]`, `[Verse]`, etc.) go to the lyric editor, while style tags (genres, instruments, moods) are automatically appended to the Style Prompt field.

* **Real-time Search & Category Filters**
  Instantly search across all 368 tags with live filtering. Horizontal category chips let you quickly narrow down to specific tag groups.

* **Accordion-based Tag Browser**
  Tags are organized in collapsible accordion panels with sub-categories for large groups like Instruments (72 tags, 6 sub-categories) and Genres (110 tags, 10 sub-categories). Lazy-loaded for performance.

* **Style Prompt Builder**
  Combine genres, moods, and vocal styles to generate optimal AI prompts, including an 'Exclude Styles' filter for precise control.

* **Pro Tips & Templates**
  13 prompt engineering tips and 10 genre-specific song structure templates ready to apply with a single click.

* **Advanced Tooltip Guide**
  Detailed explanations for every tag and technique on hover, ensuring anyone can create professional music.

## Getting Started

This project is a static web page that runs directly in your browser with no installation required.

1. Clone or download this repository.
2. Open the `index.html` file in your browser.
3. Write your lyrics, apply tags, and design your music styles using the available tools.

## Configuration

For monetization, this project uses Google AdSense.
- Create an `ads-config.js` file in the root directory.
- Add your AdSense client and slot IDs (see implementation in `main.js`).
- Note: `ads-config.js` is ignored by Git by default to protect your AdSense IDs.

# Suno Lyric Generator

**Suno Lyric Generator**는 **Suno AI (V5 & V6)**를 활용한 음악 생성에 최적화된 가사와 스타일 프롬프트를 설계할 수 있도록 돕는 전문 도구입니다.

## 주요 기능

* **368개 태그 / 12개 카테고리**
  곡 구조, 보컬, 악기, 장르, 무드, 믹싱, 사운드 이펙트 등 글로벌 Suno 커뮤니티에서 검증된 방대한 태그 컬렉션을 제공합니다.

* **스마트 태그 시스템**
  태그를 클릭하면 구조 태그(`[Intro]`, `[Verse]` 등)는 가사창에, 스타일 태그(장르, 악기, 무드 등)는 Style Prompt에 자동으로 삽입됩니다.

* **실시간 검색 및 카테고리 필터**
  368개 전체 태그를 실시간으로 검색할 수 있으며, 카테고리 칩으로 원하는 태그 그룹만 빠르게 필터링할 수 있습니다.

* **아코디언 태그 브라우저**
  태그가 접기/펼치기 가능한 아코디언 패널로 정리되어 있으며, 악기(72개, 6개 하위 카테고리)와 장르(110개, 10개 하위 카테고리) 같은 대형 그룹은 서브카테고리로 세분화됩니다.

* **스타일 프롬프트 빌더**
  장르, 무드, 보컬 스타일을 조합하여 최적의 프롬프트를 생성하며, 'Exclude Styles' 필터로 원치 않는 소리를 제어할 수 있습니다.

* **프로 팁 및 템플릿**
  13개의 프롬프트 엔지니어링 팁과 10개의 장르별 곡 구조 템플릿을 클릭 한 번으로 적용할 수 있습니다.

* **고급 툴팁 가이드**
  모든 태그와 기법에 대해 마우스 오버 시 상세 설명을 제공하여 누구나 전문가급 음악을 만들 수 있도록 돕습니다.

## 시작하기
